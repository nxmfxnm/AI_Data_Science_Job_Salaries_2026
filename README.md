# การวิเคราะห์เงินเดือนและปัจจัยที่เกี่ยวข้องกับงานด้าน AI และ Data Science ปี 2026
### Analysis of Salaries and Related Factors in AI and Data Science Jobs 2026

## สมาชิกกลุ่ม
- นางสาวน้ำฝน ทุนอ่อง
- นางสาววลีรัตน์ สุภาวงค์

## Dataset ที่เลือก
- **ชื่อ Dataset:** AI and Data Science Job Salaries 2026
- **แหล่งข้อมูล:** Kaggle
- **ผู้จัดทำ Dataset:** Udit Jain
- **ลิงก์ Dataset:** [kaggle.com](https://www.kaggle.com/datasets/uditjain13/ai-and-data-science-job-salaries-2026)

ชุดข้อมูล AI and Data Science Job Salaries 2026 จาก Kaggle เป็นข้อมูลเกี่ยวกับตำแหน่งงานด้าน AI และ Data Science ในปี 2026 ซึ่งประกอบด้วยข้อมูลเกี่ยวกับตำแหน่งงาน เงินเดือน ประสบการณ์การทำงาน การศึกษา รูปแบบการทำงาน และปัจจัยอื่น ๆ ที่เกี่ยวข้องกับการทำงาน เพื่อนำมาวิเคราะห์และนำเสนอในรูปแบบ Interactive Data Visualization

## คำถามวิจัย
1. ตำแหน่งงานด้าน AI และ Data Science มีเงินเดือนแตกต่างกันอย่างไร
2. ระดับประสบการณ์ในการทำงานมีความสัมพันธ์กับเงินเดือนหรือไม่
3. ระดับการศึกษามีความสัมพันธ์กับเงินเดือนหรือไม่
4. รูปแบบการทำงาน เช่น On-site, Hybrid และ Remote มีความแตกต่างของเงินเดือนหรือไม่
5. ขนาดและลักษณะของบริษัทมีความสัมพันธ์กับเงินเดือนของบุคลากรหรือไม่
6. ปัจจัยใดบ้างที่มีความสัมพันธ์กับเงินเดือนของงานด้าน AI และ Data Science

## วัตถุประสงค์เบื้องต้น
1. เพื่อสำรวจและวิเคราะห์ลักษณะของข้อมูลตำแหน่งงานด้าน AI และ Data Science
2. เพื่อวิเคราะห์และเปรียบเทียบเงินเดือนของตำแหน่งงานในด้าน AI และ Data Science
3. เพื่อศึกษาความสัมพันธ์ระหว่างปัจจัยต่าง ๆ เช่น ประสบการณ์ การศึกษา รูปแบบการทำงาน และลักษณะบริษัทกับเงินเดือน
4. เพื่อค้นหา Insight ที่สำคัญจากชุดข้อมูลและนำเสนอผลการวิเคราะห์ในรูปแบบ Interactive Data Visualization
5. เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับนำเสนอข้อมูลด้วย D3.js และ JavaScript Framework อีก 1 ตัว

## การเปรียบเทียบ D3.js และ Chart.js

| หัวข้อ | D3.js | Chart.js |
|---|---|---|
| การพัฒนา | ต้องเขียนและกำหนดองค์ประกอบของกราฟค่อนข้างละเอียด | สร้างกราฟได้ง่ายกว่าโดยกำหนดข้อมูลและ options |
| ความยืดหยุ่น | สูง สามารถควบคุมองค์ประกอบของกราฟได้ละเอียด | ใช้งานสะดวก แต่การปรับแต่งเฉพาะทางมีข้อจำกัดมากกว่า D3.js |
| Tooltip | สามารถสร้างและกำหนดพฤติกรรมเองได้ละเอียด | มีระบบ Tooltip สำเร็จรูปและปรับแต่งผ่าน options ได้ |
| Animation | ควบคุมได้ละเอียดด้วย transition() และ duration() | มีระบบ Animation ในตัว สามารถกำหนด duration และ easing ได้ |
| Hover / Event | สามารถกำหนด Event ให้แต่ละองค์ประกอบได้โดยตรง | รองรับ Hover และ Interaction ผ่านระบบของ Chart.js |
| Filter | สามารถเขียน Event เพื่อกรองและอัปเดตกราฟได้อย่างยืดหยุ่น | สามารถกรองข้อมูลแล้วส่งข้อมูลใหม่ให้กราฟแสดงผลได้สะดวก |
| ความยากในการเรียนรู้ | สูงกว่า เนื่องจากต้องเข้าใจการเลือกและจัดการ DOM/SVG | เรียนรู้และเริ่มสร้างกราฟได้ง่ายกว่า |
| ความเหมาะสม | เหมาะกับ Visualization ที่ต้องการปรับแต่งและ Interaction เฉพาะทาง | เหมาะกับ Dashboard และกราฟมาตรฐานที่ต้องการพัฒนาได้รวดเร็ว |

### ข้อดีและข้อจำกัดของ D3.js

**ข้อดี**
- มีความยืดหยุ่นสูงในการออกแบบ Visualization
- สามารถควบคุม Tooltip, Animation, Event และองค์ประกอบของกราฟได้ละเอียด
- สามารถกำหนดพฤติกรรมของแต่ละองค์ประกอบได้ตามต้องการ

**ข้อจำกัด**
- มีความซับซ้อนในการเขียนโค้ดมากกว่า Chart.js
- ใช้โค้ดมากในการสร้างและจัดการกราฟ
- ผู้พัฒนาต้องเข้าใจการจัดการ DOM/SVG และ Event มากขึ้น

### ข้อดีและข้อจำกัดของ Chart.js

**ข้อดี**
- สร้างกราฟมาตรฐานได้ง่ายและรวดเร็ว
- มี Tooltip, Hover และ Animation สำเร็จรูป
- ใช้โค้ดในการสร้างกราฟน้อยกว่า D3.js
- เหมาะสำหรับการสร้าง Dashboard ที่ใช้กราฟมาตรฐาน

**ข้อจำกัด**
- การปรับแต่งองค์ประกอบเฉพาะจุดมีข้อจำกัดมากกว่า D3.js
- การสร้าง Visualization ที่มีรูปแบบเฉพาะหรือซับซ้อนอาจต้องใช้ Plugin
  หรือเขียนโค้ดเพิ่มเติม
