# การวิเคราะห์เงินเดือนและปัจจัยที่เกี่ยวข้องกับงานด้าน AI และ Data Science ปี 2026
### Analysis of Salaries and Related Factors in AI and Data Science Jobs 2026

## สมาชิกกลุ่ม
- นางสาวน้ำฝน ทุนอ่อง
- นางสาววลีรัตน์ สุภาวงค์

## Dataset ที่เลือก
- **ชื่อ Dataset:** AI and Data Science Job Salaries 2026
- **แหล่งข้อมูล:** Kaggle
- **ผู้จัดทำ Dataset:** Udit Jain
- **ลิงก์ Dataset:** [kaggle.com](https://www.kaggle.com/datasets/uditjain13/ai-and-data-science-job-salaries-2026)

ชุดข้อมูล AI and Data Science Job Salaries 2026 จาก Kaggle เป็นข้อมูลเกี่ยวกับตำแหน่งงานด้าน AI และ Data Science ในปี 2026 ซึ่งประกอบด้วยข้อมูลเกี่ยวกับตำแหน่งงาน เงินเดือน ประสบการณ์การทำงาน การศึกษา รูปแบบการทำงาน และปัจจัยอื่น ๆ ที่เกี่ยวข้องกับการทำงาน เพื่อนำมาวิเคราะห์และนำเสนอในรูปแบบ Interactive Data Visualization

## คำถามวิจัย
1. ตำแหน่งงานด้าน AI และ Data Science มีเงินเดือนแตกต่างกันอย่างไร
2. ระดับประสบการณ์ในการทำงานมีความสัมพันธ์กับเงินเดือนหรือไม่
3. ระดับการศึกษามีความสัมพันธ์กับเงินเดือนหรือไม่
4. รูปแบบการทำงาน เช่น On-site, Hybrid และ Remote มีความแตกต่างของเงินเดือนหรือไม่
5. ขนาดและลักษณะของบริษัทมีความสัมพันธ์กับเงินเดือนของบุคลากรหรือไม่
6. ปัจจัยใดบ้างที่มีความสัมพันธ์กับเงินเดือนของงานด้าน AI และ Data Science

## วัตถุประสงค์เบื้องต้น
1. เพื่อสำรวจและวิเคราะห์ลักษณะของข้อมูลตำแหน่งงานด้าน AI และ Data Science
2. เพื่อวิเคราะห์และเปรียบเทียบเงินเดือนของตำแหน่งงานในด้าน AI และ Data Science
3. เพื่อศึกษาความสัมพันธ์ระหว่างปัจจัยต่าง ๆ เช่น ประสบการณ์ การศึกษา รูปแบบการทำงาน และลักษณะบริษัทกับเงินเดือน
4. เพื่อค้นหา Insight ที่สำคัญจากชุดข้อมูลและนำเสนอผลการวิเคราะห์ในรูปแบบ Interactive Data Visualization
5. เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับนำเสนอข้อมูลด้วย D3.js และ JavaScript Framework อีก 1 ตัว

## ผลลัพธ์ที่คาดว่าจะได้รับ
- ได้ชุดข้อมูลที่ผ่านกระบวนการทำความสะอาดและเตรียมข้อมูลอย่างเป็นระบบ
- ได้ผลการวิเคราะห์เกี่ยวกับเงินเดือนและปัจจัยที่เกี่ยวข้องกับงานด้าน AI และ Data Science
- ได้ Interactive Data Visualization ที่ช่วยให้ผู้ใช้งานสามารถสำรวจข้อมูลได้ง่าย
- ได้เว็บไซต์ 2 เวอร์ชัน ได้แก่ D3.js และ JavaScript Framework ที่สอง
- ได้ GitHub Repository และเว็บไซต์ที่เผยแพร่สู่สาธารณะตามข้อกำหนดของรายวิชา
- สมาชิกในกลุ่มมีประสบการณ์ในการทำงานด้าน Data Cleaning, Data Analysis, Data Visualization และ Web Development
